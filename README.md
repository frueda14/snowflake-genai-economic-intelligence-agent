# Snowflake GenAI Economic Intelligence Agent

Hands-on learning repository for building a Snowflake-based Economic Intelligence Agent incrementally.

The main learning goal is to practice Snowflake GenAI patterns that support SnowPro Specialty Gen AI preparation, while keeping the project suitable for a public portfolio repository.

## Architecture Concept

The target architecture combines public and Marketplace economic data with Snowflake semantic modeling, Cortex Analyst, document processing, Cortex Search, Cortex Agents, and a Streamlit chat interface.

Planned technologies:

- Snowflake
- Snowflake Marketplace
- Cortex AI Functions
- Semantic Views
- Cortex Analyst
- Cortex Search
- Cortex Agents
- Streamlit

Work in Progress.
