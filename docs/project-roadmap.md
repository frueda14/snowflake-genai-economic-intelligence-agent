# Project Roadmap

## Phase 0 - Repository & Project Bootstrap

Objective: Establish the public repository structure, documentation baseline, and working guidelines.

Expected deliverables: README, agent guidelines, environment template, roadmap, architecture note, learning log, and pull request template.

Status: In Progress

## Phase 1 - Marketplace Data Foundation

Objective: Explore and prepare public or Marketplace economic data sources in Snowflake.

Expected deliverables: Documented data source selection, setup notes, and initial data foundation SQL.

Status: Planned

## Phase 2 - Semantic Layer & Cortex Analyst

Objective: Define a semantic layer over structured economic data and evaluate Cortex Analyst workflows.

Expected deliverables: Semantic model assets, validation notes, and analyst query examples.

Status: Planned

## Phase 3 - Document Processing & Cortex Search

Objective: Add public economic documents and make them searchable through Snowflake-native capabilities.

Expected deliverables: Document processing notes, search configuration, and retrieval validation examples.

Status: Planned

## Phase 4 - Cortex Agent

Objective: Combine structured analysis and document retrieval into an agent workflow.

Expected deliverables: Agent design notes, tool integration assets, and test prompts.

Status: Planned

## Phase 5 - Streamlit UI, Observability & Project Polish

Objective: Build a lightweight user interface and document operational considerations.

Expected deliverables: Streamlit interface, observability notes, cost monitoring notes, and final project documentation.

Status: Planned
