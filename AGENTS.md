# Agent Working Guidelines

This repository is a public portfolio project for learning Snowflake GenAI concepts incrementally.

## Rules

- Work incrementally by project phase.
- Never invent Snowflake syntax, privileges, limits, models, or feature behavior.
- Prefer official Snowflake documentation as the source of truth.
- Do not implement functionality outside the current requested task.
- Preserve existing validated files and SQL unless explicitly asked to change them.
- Never commit credentials, tokens, private keys, Snowflake passwords, connection strings, or secrets.
- Use environment variables or ignored local configuration for secrets.
- Keep SQL organized by numbered phase directories when SQL is introduced.
- Prefer small, reviewable changes.
- When making a change, summarize what was added and any assumptions.
- Do not remove TODOs just to make the repository look complete.
- Treat this repository as a public portfolio repository.
